# Baudo Game Jam 2026 
# Don't look at me

## Le principe du jeu
* ZQSD pour se déplacer.
* Le joueur dois récupérer toutes les orbes avant que le monstre ne le voit.
* 1 2 3 4 pour activer les boosts.
